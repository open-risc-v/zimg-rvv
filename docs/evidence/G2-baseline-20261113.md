- 上游：`sekrit-twc/zimg` @ `67e0603`，graphengine 子模块 `cb5b2ce`（随快照固定）
- 构建：autotools，`./autogen.sh` + `configure --disable-shared --disable-testapp --disable-example`
- 探针：`test/pkg_zimg.c`，两条图路径，`params.cpu_type = ZIMG_CPU_NONE`（强制可移植 C）

## 踩到的坑

1. zimg 的 `graphengine` 是 submodule，`fetch-upstream.sh` 不自动 init → `make` 报
   `No rule to make target 'graphengine/graphengine/cpuinfo.cpp'`。要
   `git -C baseline submodule update --init --recursive`，再把内容同步进 `src/`。
2. libzimg 是 C++、探针是 C：不能写 `target_link_libraries(... stdc++)`——交叉 sysroot 里
   只有 `libstdc++.so.6`，没有无版本号 `.so`，`-lstdc++` 直接找不到。改用
   `set_target_properties(... LINKER_LANGUAGE CXX)`，并把 `project()` 改成 `C CXX`。
3. zimg 的 CSC 路径对格式字段很挑：RGB 侧带 `matrix_coefficients` 会被拒；
   原色/传递函数不一致会报 `no path between colorspaces`。基线改用 depth 转换（更稳、也更能代表内核工作）。
